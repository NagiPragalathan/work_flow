INTERFACE BINDING & HOSTING
A visual page is bound to a workflow and served at a shareable link — logic becomes a product.
Build Time — Builder
Assemble Page
Drag-and-drop blocks in the interface builder.
▶
Mark Action Element
Tag a button / form as the action.
▶
Bind to Workflow
Attach a workflow id to the element.
▶
Publish
Serve at a public per-page link.
▼  shareable link
Run Time — End User
Open Link
Platform serves stored page; re-applies binding.
▶
Submit Input
Embedded script gathers field values.
▶
Run Bound Workflow
Calls the trigger endpoint; engine executes.
▶
Show Result
On-chain result rendered in place.
Binding persistence: the workflow id is kept with the page and re-injected on every serve, so the application stays wired to its logic even after the visual editor rewrites the page markup.
